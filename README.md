# connected2country.au — deploy & edit

## Deploy (cPanel, Crazy Domains)
1. cPanel → File Manager → public_html/connected2country.au. Delete any placeholder files.
2. Upload `connected2country-site-upload.zip`, right-click → Extract, then delete the zip. Make sure `.htaccess` extracted (enable "Show hidden files" in File Manager settings).
3. cPanel → SSL/TLS Status → run AutoSSL for connected2country.au so the HTTPS redirect in .htaccess works.
4. cPanel → Email Accounts → create `noreply@connected2country.au` (any password; it's only the From address) and ensure `helen@connected2country.au` exists. The contact form posts to `/contact.php` via PHP mail().
5. Test: https://connected2country.au/ , /robots.txt , /sitemap.xml , /llms.txt , and send a test enquiry.

## After launch (the citations AI engines and Google actually trust)
- Google Business Profile (Fannie Bay NT, service-area business) + Bing Places
- Google Search Console: add property, submit sitemap.xml
- Directory listings: CNTA consultants list, AACAI, AAS, WA DPLH InContact (for East Kimberley), ICN Gateway, NT Gov supplier registration
- LinkedIn company page linking to the site; add URL to `sameAs` in _build.py ORG once created

## Edit
Site is generated by `_build.py` (Python 3, no dependencies). Edit SERVICES / REGIONS / GUIDES / about text, run `python3 _build.py`, re-upload `out/`.
Phone, email, ABN and address are constants at the top of the file.
